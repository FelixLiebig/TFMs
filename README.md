## KNIME-Workflow
Das Repository enthält den Workflow-Ordner `KNIME_TabularFoundationModel`. 

Lade dir hier die nötige Software herunter:

[![KNIME Download](https://img.shields.io/badge/KNIME-Analytics%20Platform-FFD800?style=for-the-badge&logo=knime&logoColor=black)](https://www.knime.com/downloads)

**Öffnen in KNIME:**
1. KNIME Analytics Platform öffnen.
2. **File** > **Import KNIME Workflow...** wählen.
3. Auf **Select root directory** klicken, den Ordner aus dem Repository auswählen und mit **Finish** bestätigen.
